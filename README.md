# darts501

飞镖 501 结镖计算器：输入剩余分数，算出以 **double**（或牛眼）收尾的结镖路线。

纯标准库（argparse、sys），无依赖。

## 用法

```bash
python -m darts501 170
# 170: T20 T20 Bull

python -m darts501 100
# 100: T20 D20

python -m darts501 32 --darts 2
# 32: D16

python -m darts501 169
# 169: 无法结镖
```

- `S20` = 单倍 20，`D16` = 双倍 16，`T20` = 三倍 20，`Bull` = 牛眼（50 分，算 double 收尾），`25` = 外圈牛眼。
- `--darts 1/2/3`：限制最多用几镖结镖（默认 3）。

## 设计取舍

- **优先更少镖数**：先找 1 镖、再 2 镖、最后 3 镖的路线。
- 同镖数下优先分值大的镖先行，符合常见打法习惯（如 170 → T20 T20 Bull）。
- 同分数保留最简记法（T20 而非 D20 D10 等价拆分里的低效记法）。

## 已知局限

- 标准规则下 169、168、166、165、163、162、159 这 7 个分数确实无法结镖（程序会如实返回"无法结镖"）。
- 只给"一条可行路线"，不是全部路线枚举，也不做对手策略考量。
- 假设标准 501 double-out 规则；double-in 开局不在范围内。
